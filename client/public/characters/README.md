# Character Art

Drop PNG/JPG/WEBP files here named `avatar_1.png` through `avatar_16.png` to
replace the default emoji avatars with real artwork.

- Recommended size: **256×256 px** (square)
- Format: PNG with transparent background works best
- The game auto-detects the file and falls back to the original emoji if
  none exists, so you can add them progressively

Tips:
- Generate art with Midjourney / DALL-E / Stable Diffusion using prompts
  like "stylized cartoon portrait of Sheikh Zayed with traditional ghutra"
- Or commission an artist for a uniform style across all 16
- Tag every image with the player's traits so your style stays consistent
